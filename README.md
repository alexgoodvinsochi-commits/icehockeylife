# Ice Hockey Life — сайт хоккейных сборов

Новый сайт [icehockeylife.ru](https://icehockeylife.ru) — хоккейные сборы для детей в Сириусе (Сочи).
Статический сайт на [Astro](https://astro.build): без админки и базы данных, открывается быстро, хостится где угодно.

Превью: https://alexgoodvinsochi-commits.github.io/icehockeylife/ (закрыто от поисковиков).

## Где что лежит

| Что поменять | Файл |
|---|---|
| Даты, цены, дедлайн ранней цены, часы, подарки, отель | `src/data/camp.ts` |
| Телефоны, WhatsApp, соцсети | `src/data/camp.ts` → `contacts` |
| Тренеры и специалисты (биографии, роли, фото) | `src/data/staff.ts`, фото — `src/assets/staff/<slug>.png` |
| Программа на льду и вне льда | `src/data/program.ts` |
| Вопросы и ответы | `src/data/faq.ts` |
| Отзывы родителей | `src/data/reviews.ts` |
| Города участников | `src/data/cities.ts` |
| Фотографии и подписи к ним | `src/assets/photos/`, `src/data/photos.ts` (неиспользуемые — в `photos/spare/`) |
| Реквизиты ИП, Политика и Согласие на обработку данных | `src/data/legal.ts` |

Блоки с датами меняются сами: после 8 ноября ранняя цена скрывается везде (первый экран, сводка, цены, вопросы,
форма), счётчик дней считается в браузере, а после окончания сборов (`overAfter`) вместо записи появляется сообщение.
Цены, даты, часы и число мест в тексте берутся из `src/data/camp.ts` — для нового сезона достаточно поменять их там.

Фото с детьми: имена на шлемах и табличках шкафчиков стёрты; новые фото проверяйте так же.

## Заявки

Форма записи не отправляет данные на сервер: она собирает сообщение (имя родителя, телефон, возраст, амплуа)
и открывает WhatsApp главного тренера с готовым текстом. Номер — `contacts.whatsapp` в `src/data/camp.ts`.
WhatsApp в России блокируется с февраля 2026 года, поэтому рядом всегда есть СМС с коротким текстом (на телефонах),
копирование текста и звонок; вернувшись из WhatsApp, родитель видит вопрос «Сообщение ушло?».

Без отмеченного согласия заявка не формируется. Сервера нет, поэтому в конец каждого сообщения добавляется строка
со ссылкой на текст Согласия (и датой редакции из `revision` в `src/data/legal.ts`) — это и есть подтверждение согласия.

## Проверки

```bash
npm run build
node scripts/smoke.mjs shots/smoke   # 47 проверок: карточки тренеров, меню, форма и её запасные каналы,
                                     # «Назад» на фото и биографиях, перезагрузка вкладки, галерея, видео,
                                     # цены до и после 8 ноября, после сборов, документы
node scripts/a11y.mjs                # axe-core: главная, /politika/, /soglasie/ на телефоне и компьютере
node scripts/shoot.mjs dist shots --full --widths=390,1440   # снимки страниц
```

Все скрипты читают `dist`; другую папку сборки можно указать переменной `DIST`
(`npx astro build --outDir scripts/tmp-dist && DIST=scripts/tmp-dist node scripts/smoke.mjs`).

Картинка для соцсетей (`public/og.jpg`) — снимок служебной страницы /og/: `npm run build && node scripts/make-og.mjs`,
затем снова `npm run build`. В боевой сборке страницы /og/ нет.

## Запуск и сборка

Нужен Node.js 22.12+.

```bash
npm install
npm run dev        # http://localhost:4321
npm run build      # готовый сайт в dist/
```

## Публикация

- **Превью** собирается автоматически при каждом пуше в `main` (GitHub Actions → GitHub Pages),
  с `PUBLIC_PREVIEW=1`: страница закрыта от индексации, Яндекс.Метрика отключена.
  Любая сборка без явного `PUBLIC_PREVIEW=0` (в том числе обычный `npm run build`) тоже закрыта: случайно
  выложить на хостинг индексируемую копию с незаполненными реквизитами не получится.
- **Боевой сайт** на icehockeylife.ru:

  ```bash
  SITE_URL=https://icehockeylife.ru PUBLIC_PREVIEW=0 PUBLIC_METRIKA=1 npm run build
  ```

  `BASE_PATH` для домена не нужен (по умолчанию `/`; в Git Bash на Windows не передавайте `BASE_PATH=/` —
  консоль подменит его на путь к папке Git). Сборка остановится с ошибкой, пока в `src/data/legal.ts`
  не заполнены реквизиты ИП, хостинг, режим работы и дата редакции документов.

  Содержимое `dist/` загрузить на хостинг статики **в России** (Timeweb, Reg.ru, Beget, Selectel):
  данные посетителей и заявки по 152-ФЗ должны оставаться в РФ, а GitHub Pages запрещает коммерческое использование.
  Затем направить DNS домена на хостинг. Метрика (счётчик 96542568) есть только в такой сборке и загружается,
  лишь когда посетитель нажал «Разрешить» в уведомлении о cookie; переходы по ссылкам и Вебвизор отключены,
  потому что в ссылках WhatsApp и СМС лежит текст заявки.
